Media guidelines

Every asset should follow these guidelines before submission.

School logo and branding

Use the institution's authorised logo and approved brand assets.

Campus photographs

Upload clear, relevant photographs with appropriate permissions.

Supporting documents

Keep brochures and PDFs current and sourced from official publications.

Rights and moderation

Check usage rights, privacy and file safety before submission.

Review before publishing

Uploading a file makes it available to your school profile tools, but a placement on the public site is only made when you select it from Profile or the relevant content page.

Media access is restricted

Media access is restricted to the representative's assigned institution. Uploading a file does not automatically make it public — you must select it for a school profile field or content placement.
