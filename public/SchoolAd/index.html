Dashboard rules

School-specific data: all records are scoped to the institution assigned to the signed-in representative.
Review workflow: edits can be saved as drafts and submitted for review. The approved public version remains visible until changes are approved.
Live statistics: counts and status labels come from the database, not fixed sample numbers.
Backend security: every API request verifies the user's identity, role and assigned school.
